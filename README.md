# 진주실크박물관 디지털 인터랙티브 웹전시
### Jinju Silk Museum - Interactive Digital Web Exhibition

진주실크박물관의 타겟 관람객(2030 청년층 및 10대 가족)을 위한 3D 가상 피팅 & 캐릭터 놀이터 인터랙티브 웹 플랫폼입니다.

---

## 🏛️ 주요 전시 구성

### 1관: 《비단실의 궤적: 실크 아뜰리에 3D 인터랙티브 가상 피팅 시뮬레이터》
- **타겟층**: 20~30대 청년층 관람객
- **체험 방식**: 모바일 웹 & 박물관 디지털 키오스크
- **핵심 기능**:
  - Three.js WebGL 기반 실시간 3D 의상 시뮬레이션
  - 전통 모던 한복(저고리 + 치마) 및 서양 이브닝 드레스 실루엣 선택
  - 저고리와 치마 색상을 각기 다르게 지정 가능한 14색 전통 비단 컬러 팔레트
  - **직조 조직 커스터마이징**: 로열 옥스퍼드 조직(Oxford Weave), 바구니, 매트골, 하운드투스, 헤링본 등 오돌토돌한 실크 질감 표현
  - **실크 레이스 프릴(Lace Trim) 온/오프**: 치마 및 소매, 넥라인에 고급스러운 반투명 레이스 장식 실시간 탈부착
  - **전통 문양 브러쉬 6종 직접 그리기 (3D 표면 실시간 자수 데칼)**:
    1. 곡두문 (기하학 번개문 띠)
    2. 쇠코결연금문 (구름 꽃띠)
    3. 돌김무늬 (전통 회문 回자 띠)
    4. 고리금문 (사슬 고리 띠)
    5. 여의두문 (여의주 삼지창 구름 띠)
    6. 구름문 (상서로운 비단구름 띠)
    - 브러쉬 모드 켜기/끄기 토글 지원 (그리기 시 360도 회전 잠금으로 섬세한 터치 가능)
    - 마우스 커서로 3D 의상 위를 클릭하거나 문지르면 3D 표면 위에 금빛 전통 문양이 실시간으로 수놓아짐
  - 국화/나비/매화/리본 3D 입체 매듭 장식 드래그 앤 드롭 커스터마이징 & 크기 조절
  - 360도 회전 및 역동적인 치마 플레어 물리 효과
  - 런웨이, 야간 미디어아트, 박물관 갤러리 조명 프리셋
  - 나만의 3D 실크 룩북 소장용 이미지 캡처 및 저장

### 2관: 《누에와 실크의 놀이터: 비단실을 뽑는 누에와 비단이의 일상 장면》
- **타겟층**: 10대 청소년 및 어린이 가족 관람객
- **체험 방식**: 모바일 터치 웹 / QR 코드 유물 연동
- **핵심 기능**:
  - **누에 요정 「실이」 모드**:
    1. 뽕잎 먹이기: 단계별 표정 변화 및 리액션 인터랙션
    2. 전통 물레 실뽑기: 1,500m(고치 1개 분량) 달성 시 즉시 다음 단계(천연염색)로 자동 전환
    3. 알록달록 천연염색: 하얀 비단 천 위에 브러시로 직접 물들이는 인터랙티브 캔버스 (염색 완료 시 비단이에게 자동 전달)
  - **한복 소녀 「비단이」 모드**:
    1. 비단 재단하기: **실이와 함께 직접 염색한 나만의 비단**을 가위로 톡톡 잘라 실제로 반으로 싹둑 분리되는 인터랙티브 재단 연출
    2. 비단 옷 짓기: **1단계에서 잘라진 두 조각의 비단을 바늘과 황금실로 지그재그 꿰매어** 한복(저고리+치마)으로 봉제 완성하는 실감 바느질 애니메이션
    3. 일상생활 적용: 왕실 곤룡포, 규방 보자기, 패션 스카프 등 비단의 가치 탐구
  - **가상 QR 유물 도슨트**: 전통 베틀, 오색 실타래 해설
  - **명예 진주실크 장인 임명장 발급**: 사용자 이름을 새긴 수료증 발급 및 이미지 다운로드

## 💻 실행 방법

별도의 서버 설치 없이 브라우저에서 바로 열 수 있습니다.

1. 본 저장소를 다운로드하거나 클론합니다.
```bash
git clone https://github.com/<your-username>/jinju-silk-web-exhibit.git
cd jinju-silk-web-exhibit
```
2. `index.html` 파일을 크롬, 엣지, 사파리 등의 최신 웹 브라우저로 엽니다.
3. 또는 간단한 로컬 개발 서버를 이용할 수 있습니다:
```bash
npx serve .
```

## 🌐 GitHub Pages 배포 안내

1. GitHub 저장소 생성 후 파일들을 푸시합니다.
2. 저장소의 **Settings** -> **Pages** 메뉴로 이동합니다.
3. **Build and deployment** 항목의 Source를 `Deploy from a branch`로 선택하고, Branch를 `main` / `/ (root)`로 지정한 뒤 **Save**를 누릅니다.
4. 수 분 내로 발급되는 배포 URL(`https://<username>.github.io/jinju-silk-web-exhibit/`)로 접속하여 체험할 수 있습니다.
